Wizard is a programmable display for cell-precise visual psychophysics built on the adaptive optics scanning light ophthalmoscope (AOSLO). It provides researchers with a simple interface for designing retina-contingent stimuli, while automatically handling the necessary real-time retina tracking, stimulus rasterization, and data logging. Wizard has been demonstrated previously in showing a novel color beyond the natural human gamut [(Fong, Doyle, Wang, *et al.*, Science Advances, (2025).)](https://www.science.org/doi/10.1126/sciadv.adu1052).
